## 📖 About The Project

**Mangal Shringar** is a full-stack e-commerce web application built for selling beautiful **Laddu Gopal Ji dresses, jewelry, and devotional accessories** online.

The platform provides a complete shopping experience for customers along with a dedicated admin dashboard for managing products and orders.

The project focuses on:

- Clean and professional UI
- Responsive design
- Secure authentication
- Product management
- Product image uploads
- Search and filtering
- Wishlist and shopping cart
- Customer orders
- Admin order management
- Production deployment
